## 先过账号这一关：1000 粉是硬门槛，年龄有两个说法

中文教程里最一致的一条是 **1000 名粉丝**。粉丝不到 1000，直播按钮可能压根不出现——不是变灰，是菜单里没有这一项。这个现象在日文资料里写得更直接：粉丝没达到 1000 人时，直播按钮本身就可能不显示。

年龄这条有分歧。多数中文教程写的是年满 18 岁；较新的日文资料写 16 岁以上可播，但 18 岁以下会限制部分功能，比如收礼物。两种说法都有出处，也都没有直接引用 TikTok 的条款原文，所以别把数字当圣旨。更可靠的判断方法是打开 App 点“+”，看底部有没有 LIVE：有，说明这个账号在当前的地区策略下已经具备资格；没有，按粉丝数、账号年龄、违规记录三项自查。

收礼物是另一套条件，比开播更严：账号使用满 30 天、没有违规记录、过去 30 天发过公开视频，三条同时满足才行。新号能播但收不到礼物，属于正常状态，不是账号有问题。

## TikTok 直播需要多少上传带宽：三个数字，三种性质

这是最容易把人带沟里的一段，因为流传的带宽数字口径完全不同。

**1.5Mbps 是平台侧的最低建议。** 行业媒体的说法是“TikTok 直播建议的上传速度至少为 1.5Mbps”，同时强调直播对网络稳定性要求极高，任何波动都可能导致画面卡顿、音质失真。这是“能播”的下限，不是“播得好”的标准。

**10Mbps 上行是留余量的经验口径。** 一家台湾营销服务商在设备清单里写的是“手机 + 环形灯 + 稳定网络（上行 10Mbps+）就够”，后面还补了一句“内容与节奏比设备重要十倍”。这家卖的是短影音代运营服务，数字带着销售语境，但 10Mbps 这个量级和实际体感对得上：1.5Mbps 是留给编码器的理论值，真实网络有抖动、有邻居抢带宽、有晚高峰。

**5Mbps 手机 / 6Mbps OBS 的说法**来自跨境圈里带推广性质的整理文章，把手机开播和 OBS 推流分开给值。方向没错——OBS 的分辨率和码率设置通常比手机高，需要更多余量——但这批文章往往同时夹带“原生住宅 IP 决定有没有流量”这类绝对化结论，数字可以当参考，结论别照抄。

三个数字怎么用：1.5Mbps 当及格线，10Mbps 当舒适线，5–6Mbps 当“手机和 OBS 分开看”的中间档。**测速要测上行，不是下行。**

### 家宽的坑：下行 500M，上行只有 10M

家用宽带是上下行不对称的。宣传页上写着 500M、1000M，说的都是下行；上行常常只有下行的十分之一甚至更少，100M 家宽的上行可能就 10Mbps，有些老旧线路只有 5Mbps 左右。而直播吃掉的恰恰是上传。

所以“我家网很快，看 4K 都不卡”和“我能稳定推流”是两件事。测速网站上那个带箭头的上传数字，才是你该看的。

行业媒体给的三条建议里，前两条你自己就能控制：用有线代替无线，减少波动和延迟；把延迟压下来，实时互动才成立。第三条是 CDN，把内容分发到离观众更近的节点来降低延迟——这属于平台和网络侧的事，你能做的是选一条到目标市场延迟低、回程优化的线路，这也是后面讨论 VPS 线路的原因。

## 网络不稳不只是卡，它可能让你被判成“录制内容”

这一条值得单独拿出来讲，因为它把“网络”从体验问题变成了账号安全问题。TikTok 面向主播的《社区自律公约》写得很直白：

> 为避免可能导致卡帧和回滚的网络问题，请使用高速网络连接开启直播。这些问题可能会被识别为缺乏互动和静止图像，因此很有可能在直播期间被判定为录制内容。

换句话说，你卡出来的那几秒静止画面，平台的判断逻辑不是“这人网不好”，而是“这可能是录播”。而用录制内容开直播，在 TikTok 直播里是被明确禁止的开播方式。

同一份公约里还有几条和“看起来像录播”直接相关：不建议播之前录好的内容；用无脸特效容易被视为互动较少；长时间离开不互动会被视为缺少互动，导致收视率受限，要暂时离开就用“结束直播”菜单里的暂停功能，而不是挂着不管。

所以“要不要为网络花钱”这个问题的答案，不是“卡了不好看”，而是“卡了可能限流”。

## 出口地区：为什么人在当地，直播按钮也会消失

这是“网络怎么开通”里最容易被忽略的一层。TikTok 按地区优化服务器和内容分发路径。一份面向日本用户的资料写得很直接：从日本国内线路直接访问时，内容有时会被当作“面向海外的内容”处理，影响直播质量，甚至根本不显示直播按钮。

它给的对策是两条：考虑 VPN 或专用回线，让 TikTok 把自己识别为该地区的用户；把 Wi-Fi 环境弄好，尽量用光回线，条件允许就通过有线 LAN 转换器把手机或平板接上网线。同一段还提醒，免费 VPN 连接不稳定，直播中途掉线的风险很高。

这里要把两件事分清楚：**VPN 或专线解决的是“平台认为你在哪”，带宽解决的是“你推得动多少数据”。** 只补一个，另一个照样拖后腿。

固定出口 IP 的 VPS 是另一条路：它给你的是一台位于目标市场、IP 在数据库里显示为家庭宽带属性的机器，你可以把它当作出口或推流运行环境，让 TikTok 看到的来源是一个“当地普通用户”。这条路的好处是 IP 属性固定、不共享、不会今天换个出口明天换个地区；代价是需要自己配置环境，而且它不改变你本地宽带的上行速度——你家里只有 10Mbps 上行，机器再好在本地这段还是 10Mbps。真要解决上行瓶颈，还是那句话：插网线、换套餐、别用 Wi-Fi。

## 手机直接播，还是电脑推流

手机是最短路径：点“+”，进 LIVE，设置标题和封面，开播。适合聊天、带货口播、日常互动这类不需要复杂画面的场景。

电脑开播要先装工具：Windows 用 LIVE Studio，Linux、macOS、Windows 都可以用 OBS Studio。走 OBS 这类第三方推流工具时，流程是先在 TikTok 侧选择直播、按提示拿到推流地址和密钥，把这两串东西填进推流工具，再启动推流。多出来的这一步配对，是电脑开播和手机开播最大的操作差别，也是新手最常卡住的地方——密钥填错一位，推流软件显示正常，TikTok 那边就是黑屏。

设备底线没那么玄：手机 + 环形灯 + 稳定网络就能起步，做带货再加一块提词板和第二机位。有经验的操盘手会告诉你，内容和节奏比设备重要十倍，这话不假，但“稳定网络”这四个字得算进设备清单里，不能省。

## FAQ

**粉丝不到 1000，怎么先攒到？**
垂直比宽泛有效：美食、美妆、游戏、宠物这类明确主题的账号比“什么都发”的账号更容易被关注，用户关注是因为能预期看到什么内容。配合每周几次趋势音源和挑战、按目标人群活跃时段发布（面向日本用户可瞄准通勤时段和晚 20 点到 24 点）、在评论区认真回复，再用 Instagram、X、YouTube Shorts 把已有粉丝导过来。这些方法不快，但都是能累积的。

**电脑能不能播？**
能。Windows 装 LIVE Studio，其他系统或需要更多画面控制就用 OBS Studio。核心是多一步：拿到推流地址和密钥，填进推流工具。

**为什么直播按钮不显示？**
两个方向查。资格侧：粉丝是否满 1000、账号是否有违规记录、账号是否太新。网络侧：出口地区是否被识别为境外流量。资格没问题就换网络环境再试，两者都排除后走官方反馈表单。

**直播卡顿，是设备还是网络？**
先测上行带宽。手机开播时把后台应用清掉、插上充电器、连有线或靠近路由器；仍然卡，再看是不是出口线路到目标市场延迟太高。设备性能不足通常表现为编码跟不上、画面糊但不一定断流，网络问题更多是花屏、音画不同步、直接掉线。

**一台机器能挂几个账号？**
跨境圈的常见做法是一个 IP 对应一个直播账号，养号阶段可以放宽到三个以内，账号越多关联风险越高。这条不是平台规则，是行业经验，但方向上和平台的风控逻辑一致。

**免费 VPN 行不行？**
